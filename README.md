# Dany Jimenez Diaz

Sitio web personal y portfolio para Dany Jimenez Diaz, preparado para desplegarse en Vercel como sitio estático.

## Archivos importantes
- `index.html`: archivo principal del sitio
- `vercel.json`: configuración de Vercel

## Despliegue en Vercel
1. Conecta este repositorio en Vercel.
2. Selecciona el proyecto y usa la configuración por defecto.
3. En "Framework Preset" deja "Other" o "Static".
4. Publica el proyecto.

La app es estática y no requiere build command ni output directory.
